# Pau Ibáñez Portfolio

A personal portfolio built with React and TypeScript, showcasing my projects,
experience, and a contact form backed by a dedicated REST API.

## Live Site

[pauibanez.me](https://pauibanez.me)

## Tech Stack

- **Framework:** React + TypeScript
- **Styling:** Styled Components
- **Analytics:** Google Analytics
- **Backend:** Custom REST API (see [portfolio-back](https://github.com/pauIbanez/portfolio-back))

## Getting Started

### Prerequisites

- Node.js 18+
- npm
- SonarQube _(Optional)_

### Installation

```bash
git clone https://github.com/pauIbanez/portfolio-front
cd portfolio-front
npm install
```

### Environment Variables

Create a `.env` file at the root based on `.env.example` with the keys:

- `REACT_APP_API_URL`
